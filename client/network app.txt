Notes

- MySQL service must be running in Windows Services before step 2, or you'll get ER_ACCESS_DENIED_ERROR / ECONNREFUSED.
- If the server says EADDRINUSE :::5000, an old instance is still alive: Stop-Process -Id <pid> -Force (find it via Get-NetTCPConnection -LocalPort 5000 -State Listen).
